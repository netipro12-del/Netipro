NETI PRO INVEST — Prototype de démonstration v0.1

Contenu:
- index.html : application web responsive
- manifest.webmanifest : configuration installable
- sw.js : cache de base pour usage hors ligne après premier chargement

Pour tester:
1. Décompresser le ZIP.
2. Ouvrir index.html dans un navigateur pour tester les fonctions locales.
3. Pour l'installation PWA et le mode hors ligne, publier les fichiers sur un hébergement HTTPS (par exemple GitHub Pages).
4. Les données sont stockées localement dans le navigateur de cet appareil.

IMPORTANT:
Cette version est une maquette fonctionnelle locale. Elle n'a ni serveur, ni authentification réelle, ni paiement Mobile Money, ni comptes membres synchronisés. Les demandes sont fictives. Ne l'utilisez pas pour collecter ou conserver de l'argent réel ou des données sensibles.
Avant lancement: avis juridique/réglementaire en RDC, étude de faisabilité agricole et élevage, prestataire de paiement agréé, backend sécurisé, gestion des rôles, journal d'audit, sauvegardes et tests de sécurité.
